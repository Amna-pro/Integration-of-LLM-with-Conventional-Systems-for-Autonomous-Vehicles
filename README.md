## Project Overview

This repository contains the complete thesis source, references, figures, diagrams, experimental visualizations, and final thesis PDF for the project. The visual material is organized chapter by chapter so the work can be reviewed directly from GitHub.

## Repository Contents

| Item | Description |
| --- | --- |
| `main.tex` | Main LaTeX thesis source |
| `first.tex` | Supporting LaTeX source |
| `mybib.bib` | Bibliography database |
| `Images/` | Original chapter figures and diagrams |
| `docs/previews/` | GitHub friendly PNG previews generated from PDF figures |
| `Amna_MAhmood_final_Thesis.pdf` | Final thesis document |
